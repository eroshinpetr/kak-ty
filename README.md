# Как ты?

Статический сайт с десятью вопросами о настроении, энергии и самочувствии. Светлый адаптивный дизайн, пошаговый опрос и итог. Подходит для GitHub Pages.

## Ответы не сохраняются

Ответы используются только в памяти открытой страницы, чтобы показать итог. Они не отправляются на сервер, не записываются в базу, cookies, localStorage или sessionStorage. При обновлении страницы, повторном старте или выходе из результата опрос начинается заново. Истории ответов и экспорта нет.

Все вопросы, оформление и вычисление результата находятся в HTML, CSS и JavaScript. PHP, MySQL, установка пакетов и сборка не нужны. Python можно использовать только как необязательный локальный веб-сервер.

## Публикация через GitHub Pages

1. Открой репозиторий GitHub для этого сайта. На GitHub Free для Pages нужен публичный репозиторий.
2. Загрузи **содержимое этой папки** в корень репозитория: `index.html`, папку `assets`, `.nojekyll` и `README.md`. Не загружай ZIP вместо файлов. Главный `index.html` должен быть в корне выбранной папки публикации.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку с файлами сайта, например **main**, и папку **/(root)**, затем **Save**.
6. Дождись завершения публикации. В Pages появится кнопка **Visit site** с настоящим адресом сайта.

Обычный адрес проекта: `https://ИМЯ_АККАУНТА.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. Для репозитория `ИМЯ_АККАУНТА.github.io` адрес будет без имени репозитория. Достаточно открыть эту ссылку на телефоне или компьютере; компьютер разработчика может быть выключен.

Публикация после загрузки может занимать до десяти минут. Изменения в выбранной ветке публикуются автоматически. Все ссылки на ресурсы относительные, поэтому сайт работает и в корне домена, и в подпапке GitHub Pages.

Официальные инструкции: [создание сайта](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [выбор источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Локальный просмотр

Можно просто открыть `index.html` в браузере. Для просмотра через HTTP из папки сайта:

```powershell
py -3 -m http.server 8080 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8080`. Ctrl+C останавливает локальный сервер.

## Файлы

```text
index.html          страница и локальная SVG-иллюстрация
assets/app.js       вопросы, переходы и расчёт итога
assets/styles.css   оформление и адаптация к телефону
assets/favicon.svg  значок вкладки
.nojekyll           публикация статических файлов без Jekyll
```

Сайт не загружает внешние шрифты, библиотеки или изображения. Итог — способ заметить своё состояние по собственным ответам.
